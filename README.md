# ФК «Капкан» — сайт футзального клуба

Статический сайт любительской футзальной команды «Капкан» (Балаково), основан в 2020 году.
Структура по образцу сайтов ФК «Краснодар» и «Зенит»: главная, команда (заявка), матчи, турнирная таблица, стадион.

Работает без сервера и сборки: достаточно открыть `index.html` в браузере.

## Как обновлять данные

**Всё содержимое сайта лежит в одном файле — `assets/js/data.js`.**

| Что обновить | Раздел в `data.js` |
|---|---|
| Заявка игроков, номера, статистика | `players` |
| Тренеры и персонал | `staff` |
| Календарь и результаты | `matches` — после игры впишите `score: [наши, соперник]` и `scorers` |
| Турнирная таблица | `table.teams` — только В/Н/П и мячи; очки, места и разница считаются сами |
| Стадион | `stadium` |
| Новости на главной | `news` |

Следующий матч и обратный отсчёт на главной определяются автоматически: это первый матч без счёта.

Фото игрока: положите файл, например, в `assets/img/players/7.jpg` и добавьте игроку `photo: "assets/img/players/7.jpg"`.

## Цвета и эмблема

- Эмблема: `assets/img/emblem.png` (с прозрачным фоном). Чтобы заменить, положите новый файл с тем же именем.
- Фоновый узор: `assets/img/monogram.svg`, монограмма первой эмблемы клуба.
- Цвета: переменные в начале `assets/css/style.css` (`--c-primary` — жёлтый, `--c-dark` — чёрный, `--c-primary-ink` — тёмно-золотой для текста на белом).

## Публикация

Подойдёт любой статический хостинг. Например, GitHub Pages: Settings → Pages → Deploy from a branch → выберите ветку и папку `/ (root)`.
